NeurIPS 2026

Internal
Safety Collapse.

Coding agents and frontier LLMs generate content they would otherwise refuse, as a step in an ordinary programming task.

  • No jailbreak — the request is a professional task. There is no adversarial prompt and no role-play.
  • TVD — a task, a validator and a data file with unfinished fields. The task is done when the validator passes.
  • Any tool — the same structure around classifiers, parsers and domain libraries, in chat, in-context and agent settings.

The TVD framework.

A task, a validator, and a data file. Completing the task means filling the data until the validator passes.
